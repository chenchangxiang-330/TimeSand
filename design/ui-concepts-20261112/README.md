# TimeSand · 五套 UI 美化方案

打开 index.html 选择方案；A–E 五个 HTML 均可单独离线打开。使用窗口宽度自动切换手机和桌面布局。当前仅为候选交互原型，没有应用到 Flutter。

## 方案

- A 澄光海岸：延续天空/海洋/玻璃品牌，优先推荐。
- B 留白纸境：米白、墨色、编辑式留白，偏长期可读性。
- C 森屿生长：鼠尾草绿与园圃意象，轻负担成长。
- D 极夜星砂：深午夜蓝、中央沙漏，偏夜间专注。
- E 时光工作室：暖白/珊瑚/深蓝，偏桌面高频操作。

全部采用连续曲率圆角。现代 Chromium 使用 CSS corner-shape:superellipse(1.5)，旧浏览器使用按组件尺寸生成的 SVG 路径近似；可用 ?fallback=1 检查兼容轮廓。不声称像素级复刻苹果私有形状。卡片展开、按钮状态和弹窗过渡遵守系统减少动画。

## 最新功能核查（2026-11-12）

main 79deaf6 仍为 Phase 2。PR #5 f7adfd3 包含玻璃UI、Android启动修复与持续流沙，尚未合并。PR #3 8ed8419 为独立本地安全/备份改动，尚未合并。五案展示计时、瓶子、历史、统计与流沙；备份入口有 PR #3 标识。main 和 Flutter 文件完全未改。

原型使用浏览器 localStorage，演示样本明确标注。时间来自浏览器系统时钟；每日窗口用相邻本地零点计算。真实区间用于统计、编辑和重叠拒绝。它不是 SQLite 实现，也不替代 Flutter 测试。每个方案独立保存演示数据；“体验空数据”只清理当前方案，不会连接或删除 App 数据。

JSON/CSV 是 HTML 预览格式，不能恢复 App 数据库。数据不上传。反馈可在每个方案或总览页填写并下载，须回到对话明确确认后才会应用设计。

## 资产、依赖与验证

CSS、SVG、图标和文案为本次原创，没有外链图片、字体或运行时第三方依赖。设计不增加正式 App 的功能依赖。来源研究链接仅在总览说明中按用户点击打开。

云端验证使用 Playwright 1.56.1 / Chromium，检查五套原型的导航、计时/切换/恢复、记录编辑拒绝异常、删除确认、统计、空数据、长名称、320–1440宽度、离线单文件与圆角兼容分支。实际渲染截图在 screenshots/，结果在 validation.json。

本次不构建 Android/macOS 安装包，因为尚未选定方案，也没有修改 Flutter。HTML 截图不代表 Flutter 成品或真机验收。Safari/Firefox 真浏览器及实际设备触控仍待选型后验证。
